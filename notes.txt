Difference between Associations and Composition

Assocition and Compostion used for Fetching the data between Tables (Multiple Tables)
but in Assocition we can not do Deep Insert Opertaion means we can not insert the data in to multiple tables
but in Compoistion we can insert the data into multiple tables
If we use compostion if delete parent item child items also delete we can call relationship dependent means 
but in Assocition if we delete parent item only parent items will delete  we can call relation ship independent
